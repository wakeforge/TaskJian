Features

为"深度任务管理"而生的桌面工具

不止是清单。树形拆解、多维过滤、纯文本语法，专注把复杂的事理清楚。

🌳

无限层级任务树

任务可无限嵌套子任务，一键创建子项并继承分组，大目标层层拆到可执行。

🏷️

优先级标签

紧急 / 高 / 中 / 低四档彩色标签开箱即用，支持自定义名称与颜色。

🔍

多维组合过滤

搜索、分组、标签、状态四个维度任意组合，回车即筛，一眼锁定关键任务。

📝

纯文本语法

缩进定层级、前缀定状态、#标签随写随挂，粘贴一大段文字即成任务树。

🗄️

归档而非删除

完成的项目整体归档，不占用主列表；需要时可搜索找回或彻底删除。

🔒

数据全本地

JSON 原子写入本地磁盘，多工作区隔离，无需联网、无需注册账号。

How to use

三步，任务树就长起来了

不需要学习成本，装好就能用。

1

新建工作区

按项目或领域创建独立工作区，每个工作区有自己的任务树与分组。

2

录入与拆解

点「新建」录入任务，用「创建子项」逐层拆解；或直接粘贴纯文本批量导入。

3

过滤与归档

按状态、标签、关键词过滤聚焦当下；整树完成后归档，主界面保持清爽。
